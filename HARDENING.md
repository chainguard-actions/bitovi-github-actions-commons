### github-env-injection (severity: high)

In `export_vars.sh`, line 10 writes the entire contents of `bo-out.env` directly to `$GITHUB_OUTPUT` using `cat $BO_OUT >> $GITHUB_OUTPUT` without any newline sanitization (`tr -d '\n\r'`). The `bo-out.env` file is generated by `generate-outputs.sh` from `terraform output | sed ...`, which can contain values derived from user-controlled inputs (e.g., resource identifiers and names that flow from `inputs.*` through the action). An attacker could craft input values containing embedded newlines to inject additional key=value pairs into GITHUB_OUTPUT, potentially overwriting outputs consumed by downstream steps.
